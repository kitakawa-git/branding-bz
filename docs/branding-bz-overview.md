# branding.bz — プロダクト概要

## 何をするサービスか

中小企業のブランドを **「構築 → 浸透 → 発信」** まで一貫支援するSaaSプラットフォーム。
2010年の創業以来培ったブランディングコンサル経験をAI×SaaSに昇華し、従来コンサルに数百万円かかっていたブランド構築を月額サブスクリプションで実現する。

**本番URL:** https://branding.bz
**運営:** ID INC.（川崎市、CEO：北川巧）

## レイヤー構造

**構築 → 浸透 → 発信。計測が、その全部を貫く。**

| レイヤー | 何をするか | 誰が使うか | 課金 |
|---------|-----------|-----------|------|
| **構築**（つくる／ミニアプリ群） | カラー定義・STP分析・理念・ペルソナ等をAIガイドで策定 | 経営者・ブランド担当 | 無料〜フリーミアム |
| **浸透**（ひろげる／本体） | ブランド掲示・Good Action・KPI/目標・学習・理解度テスト | 管理者・全社員 | 月額サブスク |
| **発信**（とどける／スマート名刺） | QR→個人プロフィール＋企業ブランドページ。閲覧トラッキング＋マイクロFB | 全社員が外に持ち出す | 本体に含む |
| **計測**（はかる／ブランドスコア）＝**横串** | 上の3つを数字で評価する。ステップではない | 管理者・経営層 | Premium 以上 |

**計測は独立したステップではなく、3つを横串に通す軸**。実装がそうなっている＝
インナースコアは浸透の測定、アウタースコア（名刺閲覧・マイクロFB）は発信の測定、
理解度テストの設問は `brand_guidelines` / `brand_visuals` / `brand_personas`（構築で定義した
ブランドデータ）を正解キーに生成される。**計測は3つすべてを参照しないと成立しない。**
逆に発信は構築の下流・計測の上流であって、横断はしていない。

⚠️ 2026-08-31 に計測を横串へ戻した（一時、計測を独立ステップ・発信を横串とする記述にしていた）。

## 差別化ポイント

1. **インナー×アウター両方を測定できる唯一のツール** — 社員サーベイ（インナー）＋名刺閲覧データ＋マイクロFB（アウター）の統合計測は競合にない
2. **AIでブランドをセルフ構築できるSaaSは日本にほぼない**（構築領域はブルーオーシャン）
3. **コンサルの民主化** — 構築→浸透→発信→計測を1プロダクトで完結
4. **名刺×ブランドストーリーの融合** — デジタル名刺サービスは多いが、ブランド掲示との統合は未開拓

### 主な競合との位置づけ

- **B-SCORE**（トゥモローゲート社）: インナー測定のみ。branding.bzはインナー＋アウター両面
- **Unipos / THANKS GIFT / TUNAG**: 称賛・エンゲージメント特化。ブランド構築機能なし
- **Eight / Sansan / Prairie Card**: 名刺管理特化。ブランド浸透との連動なし

## ブランドスコア機能（主要差別化機能）

branding.bzに蓄積されたブランドデータを基準に、インナー（社員サーベイ）とアウター（名刺閲覧行動＋マイクロFB）の両面からブランド浸透度を定量化。

- **インナースコア:** WHY（理念共感）×35% + HOW（方針理解）×30% + WHAT（行動一致）×35%
- **アウタースコア:** 到達力20% + 関心度20% + ブランド遷移率25% + 関与度20% + 印象一致度15%
- **総合スコア:** インナー50% + アウター50% → ランク S〜D
