## 技術的な判断・学び

| 判断 | 理由 |
|------|------|
| `react-native-svg` 不採用 | dev client で動作せず。`expo-image` + base64 SVG で代替 |
| `KeyboardAvoidingView behavior="height"` | iOS で `padding` より安定した挙動 |
| FontAwesome6 への統一 | 検索アイコンの視覚的一貫性のため MaterialCommunityIcons から移行 |
