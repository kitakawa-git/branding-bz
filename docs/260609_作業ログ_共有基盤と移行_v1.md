## 1. 方針（決定事項）

- 大原則: .md（知識・指示・要件・進捗）＝ GitHub ／ 実ファイル（Excel・図・PDF・成果物）＝ Google ドライブ ／ コードは Drive外のローカル `~/dev`（GitHub正本）。
- 共通ルールは各リポの CLAUDE.md 本文に直書き（Coworkは @import を展開しない可能性が高いため）。Claude Code用に `~/.claude/CLAUDE.md` にも設置済み。
- 作業の入口: 開発・ルール適用をするときは Cowork/Code とも最初に `~/dev/<repo>` を開く。
- 命名: コードのパスは ASCII・スペースなし。Drive資料は日本語可だが /・スペース・() は避ける。
